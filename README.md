# RAAI Operations Root Site

Static GitHub Pages site intended for `https://raaioperations.github.io/`.

## Files
- `index.html` — one-page business/portfolio site
- `styles.css` — responsive shared styles
- `privacy.html` — Privacy Policy
- `terms.html` — Terms of Use
- `refund.html` — Refund Policy
- `favicon.svg` — lightweight favicon
- `.nojekyll` — disables Jekyll processing
